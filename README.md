# AI Explainer Video Studio

An Autonomous, Multi-Agent AI Video Production Studio that transforms raw prompts, pre-written scripts, or uploaded educational PDFs into finalized **1080p Full HD MP4 videos**.

---

## Quick Start

### 1. Start Backend
```powershell
cd backend
.\venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 2. Start Frontend
```powershell
cd frontend
npm.cmd run dev
```

### 3. Open Studio
Navigate to `http://localhost:5173` in your browser.
